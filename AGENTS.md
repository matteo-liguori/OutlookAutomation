# Mail and calendar assistant

Work in this project. Use `monitor.ps1` on Windows or `.venv/bin/python -m monitor`
on Mac. Start with `briefing`; follow its paging and relevant `help <topic>`.
Use `outlook status` for available capabilities. SQLite holds current work and grants.

User behaviour lives in private `customisations.yaml`; use `config show --explain`.
Keep private data and executable extensions in the configured data root, outside Git.
Sending, calendar writes and custom actions need applicable authority and verified
outcomes. Preserve read state and disclose incomplete coverage.

Setup: README.md. Development/layout: docs/development.md. Keep rules brief and in
one home. Temporary executable work uses private `scratch/OneOff.ps1`, reset after
use. Commit reusable code, defaults and tests; keep experiments in private bundles.
