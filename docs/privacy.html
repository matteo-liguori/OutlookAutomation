Privacy policy

Outlook Automation Harness is a personal tool run by its owner on the owner's own computer.

What it accesses

With the owner's consent it reads and edits events on the owner's own Google Calendars through the Google Calendar API.

Where data goes

Calendar data and sign-in tokens stay on the owner's computer. They are not sent to any server operated by the developer, sold, shared or used for advertising. The tool has no servers and no analytics.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
